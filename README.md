# Markdown Preview

Quick Look preview for Markdown on macOS.

Requires Xcode 26 or later.

## Install

```sh
git clone https://github.com/salvcy/markdown-preview.git
cd markdown-preview
./build.sh
```

## Use

Select a `.md` file in Finder and press Space.

## Uninstall

```sh
./build.sh uninstall
```
